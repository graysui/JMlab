# Jellyfin 兼容接口

JMlab 提供兼容接口，供客户端访问同一套媒体和用户状态。此说明不承诺所有 Jellyfin 功能或客户端完全兼容。

## 作为客户端的媒体服务端

JMlab 可以作为模块与第三方播放器之间的服务端。模块提供内容信息和视频地址，主程序组织媒体库并处理权限、播放信息与观看状态。使用远程视频模块时，不需要在 JMlab 服务器上预先下载和保存完整视频，也不需要额外运行一套 Jellyfin 服务端。

1. 先在 Web 中安装并配置模块，导入内容，创建虚拟媒体库，为用户授予访问权限。
2. 在支持 Jellyfin 服务连接的客户端中填写 JMlab 的访问地址，例如 `http://服务器IP:8097` 或配置好的 HTTPS 域名；不要在地址后添加 `/login` 等页面路径。
3. 使用 JMlab 账号登录，在客户端浏览目录并播放。支持同时连接 Emby / Jellyfin 的应用应选择 Jellyfin 连接方式；仅支持 Emby 协议的应用需另行适配和验证。

初始设置和模块维护通过 Web 完成；日常观看可主要使用客户端。服务器仍需为数据库、配置、媒体信息、观看记录和缓存保留持久化空间。是否存在可播放视频由模块负责，兼容接口不会自动提供视频资源。

## 已实现的宿主链路

- 登录、用户及系统信息，媒体库、详情、图片、合集和清单。
- Movie、Series、Season、Episode、Video 及父子目录、分页和权限过滤。
- PlaybackInfo、MediaSources、音轨及字幕参数、签名媒体中继。
- HTTP Range、HLS 清单与子资源、外挂字幕。
- 播放事件、分用户进度、Resume、收藏和已看状态。

媒体模块返回容器、时长、64 位文件大小和轨道；宿主转换为兼容字段。未返回的编码或轨道不会伪造。模块安装、配置和启停后，兼容客户端使用同一注册表与适用库范围，旧版本签名失效后需重新获取播放信息。

## 限制

主程序不提供实时转码。客户端必须支持实际格式，DirectStream 中继不等于转码成功。HLS 和外挂字幕仍检查当前用户、媒体授权和模块版本。

自动测试使用临时库和 HTTP 模拟媒体，覆盖选源、单集、权限、轨道、Range/HLS/字幕、续播和热启停。真实视频解码、不同设备和客户端版本需另外记录。SQL 方言检查不能替代 PostgreSQL 实测。

模块实现见[模块指南](module-developer-guide.md)，接口字段见[API 参考](openapi.yaml)。
